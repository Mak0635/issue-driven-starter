## #10 参加者画面: 投稿を送る・一覧を自動更新する
担当: B / 目安 2.5時間 / ラベル: `担当:B` `MVP`

### やること
- [ ] 「質問する」「感想を書く」を押したら記入欄を出す（`hidden` を外す）。押した方の色が変わる。同じボタンをもう一度押すか、送信したら閉じる
- [ ] 送信ボタンで `POST /api/posts`。空なら送信ボタンを押せないようにする
- [ ] Enter で送信、Shift+Enter で改行（日本語変換中の Enter は送らない: `e.isComposing`）
- [ ] **3秒ごと** に `GET /api/state` → 一覧を **古い順（新しいものが下）** で描き直す。タブが裏にあるとき（`document.hidden`）は取りに行かない
  - 描き直す前後で `scrollTop` を保存・復元して、読んでいる位置がずれないようにする
  - 開いたときと、自分が送信したときは一番下までスクロール
- [ ] 本文は **`textContent`** で表示する
- [ ] POST の返事が OK でなければ（`!res.ok`）、`/api/state` を取り直して描き直す
- [ ] ⭐ タブ（一覧／質問／感想）と件数
- [ ] ⭐ LINE のような **「ここから未読」の線** とタブの **「未読N」**
  - 「読んだ投稿の id」を `Set` で覚える（開いたときにある投稿と、自分の投稿は最初から読んだことにする）
  - スクロールするたびに、まだ読んでいないカードの位置を `getBoundingClientRect()` で調べ、上の固定部分と下の記入欄の間に **6割以上映ったら（または上に通り過ぎたら）** 読んだことにする
  - 線は「まだ読んでいない一番古い投稿」の上に出す。**未読が残っている間は線を動かさない**。全部読んだあとに新しい投稿が来たら、そこへ移す
  - タブの「未読N」は、読んでいない投稿の数。0 になったら消す
- [ ] ⭐ 送信後に「質問を送りました（匿名）」と小さく表示

### 変更する場所
`public/js/participant.js`, `resources/views/participant.blade.php`

### 完了条件
- 2つのブラウザで開き、片方で投稿すると、もう片方の一覧の一番下に数秒で出る
- 新しい投稿が来ても、読んでいるカードの位置が動かない
