# フッターにお問い合わせ先とリンクを追加する

## 概要
フッターにコピーライトしかないので、お問い合わせ先とリンクを追加したい。

## やること
- [ ] お問い合わせ先のメールアドレスを追加する（架空のものでOK。例: `team@example.com`）
- [ ] リンク一覧を追加する（GitHub など。例: `https://github.com/`）
- [ ] リンクは横並びにする（ヒント: `<ul class="flex justify-center gap-4">`）
- [ ] `&copy; 20XX チーム名` を正しい年とチーム名に変える
- [ ] （余裕があれば）リンクにマウスを乗せたら色が変わるようにする（例: `hover:text-white`）

## 変更する場所
`index.html` の **【Issue #3 担当】** と書かれたコメントの間だけ

## 完了条件
- フッターにメールアドレス・リンク・正しいコピーライトが表示されている
- リンクをクリックすると、そのページに移動できる
- 【Issue #3 担当】の範囲の外は変更していない

## ヒント
- メールリンク: `<a href="mailto:team@example.com">team@example.com</a>`
- 別タブで開くには: `<a href="..." target="_blank">`
- 余白を空けたい時は `mb-4`（下に余白）などを使います
