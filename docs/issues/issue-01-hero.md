# ヒーローセクションをチーム仕様にする

## 概要
トップのヒーローセクション（サイトを開いて最初に見える部分）が仮の文字のままなので、チームのオリジナルにしたい。

## やること
- [ ] `<h1>` の「チーム名が入ります」を、自分たちのチーム名に変える
- [ ] 「ここにキャッチコピーが入ります」を、チームのキャッチコピーに変える
- [ ] 背景色 `bg-gray-300` を好きな色に変える（例: `bg-blue-100`）
- [ ] ボタンの色 `bg-gray-500` を好きな色に変える（例: `bg-blue-600`）
- [ ] （余裕があれば）ボタンにマウスを乗せたときに色が変わるようにする（例: `hover:bg-blue-700`）

## 変更する場所
`index.html` の **【Issue #1 担当】** と書かれたコメントの間だけ

## 完了条件
- ブラウザで開くと、チーム名・キャッチコピー・新しい色が表示されている
- 【Issue #1 担当】の範囲の外は変更していない

## ヒント
- Tailwind の色一覧: https://tailwindcss.com/docs/background-color
- 色の名前（blue, green, pink…）と濃さ（100〜900）を組み合わせて使います
